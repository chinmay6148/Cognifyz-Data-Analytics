# 📊 Cognifyz Data Analytics Internship

## 📌 Project Overview

This repository contains all tasks completed during my **Data Analytics Internship at Cognifyz IT Solutions**.

The project demonstrates practical data analysis using Python, including data preprocessing, visualization, statistical analysis, and business insights from a restaurant dataset.

- Jupyter / VS Code
